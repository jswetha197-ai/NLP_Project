
# Behavioral Alpha Trading System (NLP + Fear & Greed Index)

A real-time sentiment-based trading system that generates BUY / SELL / HOLD signals using NLP-based market sentiment, a Fear & Greed Index (FGI), live price data, and an automated signal engine with a Streamlit web dashboard.



## Features
- Real-time price simulation
- NLP-based sentiment analysis (Mock, FinBERT-ready)
- Fear & Greed Index (FGI)
- Automated trade signal generation
- SQLite database storage
- Live Streamlit web dashboard
- Modular Python architecture
- Google Colab & local machine compatible

## INSTALLATION
git clone https://github.com/jswetha197-ai/NLP_Project.git
cd NLP_Project
pip install streamlit pandas numpy

## USAGE
Run the trading engine:
python main.py

Run the Streamlit dashboard:
streamlit run behavioral_alpha/dashboard/app.py
